# 脉冲穿行 v1.1 音频验证

执行命令：`node --test tests/audio.test.cjs`。2026-09-22，使用已安装 Google Chrome、Playwright 及浏览器真实 OfflineAudioContext 音频节点，22050 Hz 双声道渲染。

共 14 项检查通过：五段主要音效、左右换道与精准跳跃及倒计时反馈、全部三章音乐、总静音、独立音乐开关、暂停恢复、重复节拍去重及突发声部释放。所有浏览器 JavaScript 错误为 0。

音频上下文的时钟与运行状态通过代理控制；振荡器、滤波、音量包络、声像和压缩器均由 Chrome 实际计算。暂停/恢复检查覆盖 Soundscape 调用和声部清理，不替代 Android 音频设备测试。
