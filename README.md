# 脉冲穿行 · PULSE RUNNER

made in yongchao

一款适配安卓触屏的离线反应闯关游戏，包含 **15 关**。自动前进、左右变道、准确跳跃；碰撞即失败，可以立即重新挑战。

**[下载最新版安卓 APK](https://github.com/mrsadsad/pulse-runner/releases/download/v1.5.1/PulseRunner-1.5.1.apk)** · [查看发布记录](https://github.com/mrsadsad/pulse-runner/releases/tag/v1.5.1)

电脑上下载或克隆本仓库，安装 Node.js 后，在项目目录运行 `npm run preview`，按终端提示打开本机地址。Windows 也可以双击 `开始游戏.cmd`。本机预览地址不提供公网访问。

项目采用 AI 辅助开发。当前仓库保留游戏与构建源码、测试和验证说明；安卓签名私钥、下载工具链、个人销售材料与临时日志不包含在内。自行构建及签名步骤见 [安卓构建说明](README-android.md)。

## 安装与游玩

1. 从上面的发布页下载 `PulseRunner-1.5.1.apk`，发送到安卓手机并打开；自行构建的 APK 位于 `dist/`。
2. 按手机提示允许当前来源安装应用，完成后打开「脉冲穿行」。
3. 点击「开始穿行」，阅读当关提示后出发。

支持 Android 7.0 及以上，请使用已更新的 Android System WebView。安装后无需网络。进度和声音、震动设置自动保存在本机，卸载后会清除。

已有 1.0.0–1.5.0：直接安装 1.5.1 覆盖更新，**不要先卸载**。新版沿用原包名、签名和存档位置。电脑版本仍双击 `开始游戏.cmd`；已打开的页面刷新即可更新。

## 1.5.0 更新：手机操作与存档迁移

入口在 **首页右上角设置 →「手机操作设置」或「存档备份与迁移」**。

手机操作支持：

- **三种按钮布局**：跳跃居中、靠左或靠右，左右变道按钮保持方向含义。
- **按钮加大与底部抬高**：适应拇指操作，抬高可减少触到手机底部系统手势的机会。
- **三档滑动灵敏度**：灵敏、标准、稳健；默认沿用原来的 24 像素横移 / 28 像素上滑阈值。每次滑动只执行一次操作，不需等松手。
- **减少误触**：可只用按钮和键盘，也可单独关闭轻触赛道跳跃、保留滑动。拖动后回到起点、下滑、长按和已取消的触点不会误作轻触跳跃。
- **试手感区域**：设置页可试按钮与手势，不改变任何游戏成绩。游戏暂停后也能进入操作设置，返回暂停页再继续原来的一局。

设置自动保存在本机，恢复默认只影响触控选项；键盘按键、引擎冷却时间、碰撞判定和赛道难度不变。

存档迁移步骤：

1. 在原设备结束本局，打开「存档备份与迁移」，选择 **导出备份文件**。电脑通过浏览器下载 JSON 文件，安卓通过系统文件选择器选择保存位置；也可查看并复制完整备份文本。
2. 把文件带到另一台设备，在同一入口选择 **选择备份文件**，或粘贴完整文本并点击 **检查并预览**。
3. 核对主线通关、星数、成就、解锁与影子数量，再选择 **确认合并** 或 **确认替换**。文件读取和预览本身不会写入进度。

默认合并保留两份存档中更好的星级、进度、得分、连击和距离；尝试次数、胜利次数取较大值，不相加，重复导入不会刷高次数。设置和当前装备保留本机选择，导入的成就照常解锁奖励。不同日期的每日记录合并后保留最近 60 条，已有成就不会因历史裁剪丢失；影子按相同路线择优并遵守原有容量限制。

选择替换会使用备份中的全部进度、设置与装备，可能少于本机现有成绩。每次成功导入前都会先保存一份 **导入前恢复点**；在同一页面可预览并恢复它。恢复会替换当前进度，也会撤回导入后新玩的成绩，因此可先导出当前备份；恢复成功后清除该恢复点。若恢复点无法保存或主存档写入失败，则停止导入并保留当前进度。导入确认前检测到其他页面改变存档时，也会停止本次操作。

备份包含主线、变式、每日、机关、无限模式的记录，成就、装扮、声音与触控设置，以及容量内的最佳录像。正在进行的一局与临时失败回放不包含在内。支持完整的旧版原始存档，并在预览中标明缺少校验；无关 JSON、未知格式、损坏校验或过大的文本会被拒绝。备份的校验和用于发现传输误改，不提供加密或防作弊功能。

电脑与安卓之间是手动迁移，不会自动同步。朋友挑战码只传递路线，不能作为存档导入。导入、导出与恢复不需要账号或额外存储权限；卸载或清除应用数据会删除本机存档和本机恢复点，请把备份文件另外留好。

## 1.4.0 更新：回看操作与成就装扮

- **失败回放**：失败结算选择「慢放最后几秒」，查看本局最后最多 6 秒的实际变道、起跳和碰撞。默认半速，可暂停、切换正常速度、拖动时间条或从头回看；返回结算后可重试或练习。主线、变式、每日、机关与无限模式均支持，练习失败也能回看。
- **最佳录像影子**：正式挑战结束后，按同路线已录制的最高得分保存操作；再次进入该路线时显示轮廓影子和同时间点的分数差。暂停页或游戏设置中可关闭显示。影子不参与碰撞，也不影响得分；练习可以参照影子，但不会覆盖正式录像。
- **装扮收藏**：首页 → 挑战中心 →「装扮收藏 · 机体与尾迹」。2 件初始装备加上 10 件成就奖励，共 6 种机体、6 种尾迹，可分别搭配并实时预览。达成成就会自动解锁，已有存档的成就直接计入；装扮只改变外观，碰撞范围、速度和分数不变。

回放记录实际游戏状态，不重新模拟按键。只回看当前失败的一局，重新挑战或离开结算后清除；回看、暂停、切换速度与返回结算不会再次写入成绩。切换到后台会暂停回放，回到游戏需手动继续。

影子从 **1.4.0 更新后的正式挑战**开始记录，旧成绩不会凭空生成录像；所以「最佳录像」分数可能低于更新前的历史最高分。主线与挑战模式分别记录，变式按模式区分、每日按日期区分、无限按种子区分，只有相同路线才显示。最多缓存 6 条路线、合计 24,000 字符；容量不足时移除较旧的录像，历史成绩与已解锁奖励不受影响。每条最多记录前 120 秒或 256 个状态变化，密集操作可能提前达到容量；准备页和游戏内会显示实际记录截止时间，超出后隐藏影子。

| 成就 | 解锁奖励 |
| --- | --- |
| 首次正式通关 | 机体「初燃」 |
| 完成 5 个主线关卡 | 尾迹「双轨」 |
| 完成全部 15 个主线关卡 | 机体「极光梭」 |

镜像疾速通关可同时计入镜像与疾速目标；成就条件与 1.3.0 一致。录像和装备随原存档自动保存在本机，无需账号或网络。

## 1.3.0 更新：机关试炼与无限生存

首页进入「挑战中心」，最上方是两个新入口。原有 15 关、变式和每日挑战的路线保持不变。

- **机关试炼**：沿用原来 15 条赛道的时长和节奏，重新安排移动高墙、周期闸门与风险奖励路线。全部可直接选择，成绩与主线分开。
- **移动高墙**：蓝色高墙在接近过程中横移，箭头和轮廓提前标出最终落点；到达判定线前 0.9 秒停止移动，高墙仍不能跳过。
- **周期闸门**：远处周期性开合，到达判定线前 0.9 秒锁定状态。框架内为空时可通过，关闭时需要变道。
- **路线选择**：普通晶体所在通道可直接通过；跳过另一条通道的矮栏或断层，可收集金色奖励，额外获得 200 分。每排最多计入一枚晶体和一次连击，选择普通路线也可获得三星；高分路线的额外奖励单独展示。
- **无限生存**：没有终点，路线持续生成，每 25 秒进入新阶段，难度在第 8 档封顶。碰撞结算；暂停后可主动结束保存、保存后重来或结束返回挑战中心。
- **可重复的路线**：无限模式重试使用同一条路线，选择「换一条路线」才改变组合。机关试炼和无限模式均可复制 PR3 挑战码，让朋友在自己的设备重玩同一条路线。PR2 挑战码继续有效。

机关试炼支持整关和失败片段练习，练习不改变正式纪录。无限模式单独记录最远距离、最高分、最长时间、最高阶段、连击与风险奖励次数；不同纪录可能来自不同局。机关试炼通关可获得「首战告捷」，两个新模式的正式连击可计入原有连击成就；它们不增加主线星数或解锁进度。

无限路线按需生成并移除已远离的路段，避免随游玩时间持续积累全部障碍。关闭或强制结束应用不会恢复进行中的一局；离开前可在暂停界面结算保存。

## 1.2.0 更新：挑战与成长

从首页进入「挑战中心」，可游玩以下新增内容：

- **三种变式**：15 条原赛道均可选择镜像（左右翻转）、疾速（速度提高 15%）、镜像疾速，共 45 种变式组合。疾速会同步缩短赛道时长和障碍间隔。
- **每日挑战**：根据本机日期，从现有赛道和三种变式中确定当天的固定组合。当天不限重试；挑战中心会更新当天日期，已准备或进行中的挑战及其重试保持原日期。
- **朋友挑战码**：结算页复制挑战码，朋友在挑战中心输入即可打开同样的赛道和规则。比如 `PR2-L05-M` 是第 5 关镜像，`PR2-20260922` 是指定日期的每日挑战。无需账号或网络；分数各自保存在本机，可手动比对，没有在线排行榜或联机对战。
- **10 项成长目标**：首次通关、主线推进、星数、连击、镜像与疾速通关、不同日期的每日挑战等目标，显示进度并在达成时提示。已达成的目标保留，旧存档可直接计入已有主线成绩。
- **独立纪录**：主线、各赛道变式、每日挑战分别记录最高分、连击、星数和尝试次数。独立挑战开放所有赛道，但不解锁主线；所有练习均不更新正式成绩与成就。

主线仍是原来的 15 关，按通关顺序解锁。每日详细纪录保留最近 60 个日期，界面展示最近 5 个；已保存的成就进度不随旧纪录轮换消失。镜像和疾速的成长目标按不同赛道计数，重复刷同一赛道不会重复计入。

每日挑战使用本机日期，不依赖服务器；过去日期可通过挑战码重玩。更新覆盖安装可保留进度，卸载或清除应用数据会删除本机存档。

## 操作

| 操作 | 手机 | 电脑预览 |
| --- | --- | --- |
| 向左 / 向右变道 | 底部左右按钮，或在赛道左右滑动 | ← → / A D |
| 跳跃 | 跳跃按钮（默认居中），或轻触赛道 | 空格 / ↑ / W |
| 暂停 | 左上角暂停按钮，或安卓返回键 | P / Esc |

高墙为橙红色，必须换道；金色矮栏和黑色断层可以跳过。跨两条轨道要操作两次，跳跃过程中也能换道。跳跃约 0.82 秒；落地前 120 毫秒内按下跳跃，会在落地后接续一次。按住不会连续自动跳。

通关得一星；收集至少 70% 晶体得两星；收集全部晶体得三星。通关后解锁下一关，已解锁的关卡可以自由重玩。最佳星数与最佳进度不会被较差成绩覆盖。

每通过一排障碍得 25 分，每枚晶体得 100 分；连续收集每次额外增加 25 分，单枚连击奖励最多 200 分；通关另得 1,000 分。漏掉晶体会中断连击。练习分数仅供当次参考，不计入正式纪录。

## 源码与构建

- `web/`：界面、Canvas 绘制、游戏引擎与全部关卡，无前端运行依赖。
- `web/renderer.js` / `web/audio.js`：分章节场景与反馈绘制、完全离线的声音合成。

- `web/expedition.js`：机关试炼与按种子生成的无限路线；`web/expedition.css`：新模式入口、提示和结算样式。

- `tools/bootstrap-android.py`：下载并核验官方构建工具，工具存放在当前项目内。
- `tests/engine.test.cjs`：碰撞、跳跃、存档与 15 关通关验证。
- `tests/challenges.test.cjs` / `tests/progression-save.test.cjs`：所有模式通关、日期与挑战码、独立纪录和存档兼容验证。

- `tests/replay.test.cjs` / `tests/rewards.test.cjs` / `tests/profile.test.cjs`：回放状态还原、容量与身份隔离、成就奖励、存档兼容；`tests/replay-browser.test.cjs`：回放、影子和装扮的实际触控流程。
- `tests/controls.test.cjs` / `tests/backup.test.cjs`：手势边界、设置清洗、备份校验与合并；`tests/comfort-browser.test.cjs`：触控调整、文件迁移、恢复和写入失败场景。
- `qa/`：测试记录与实际截图。

电脑直接游玩：在完整解压后的项目文件夹中，双击 `开始游戏.cmd`，会自动用默认浏览器打开游戏。安装了 Node.js 时使用本机地址 `http://127.0.0.1:4185/`；没有 Node.js 时直接打开内置的 `web/index.html`，游玩无需安装开发工具。

这个地址只在运行启动程序的电脑上可用，不是公开网站。电脑重启后，再双击 `开始游戏.cmd` 即可。键盘 ← → / A D 变道，空格跳跃。安卓手机请使用上面的 APK 安装方式，APK 不能直接在 Windows 中运行。

开发预览仍可运行 `npm run preview`；直接打开 `web/index.html` 也可游玩。浏览器版本和安卓应用各自保存进度。

逻辑测试：`npm test`。浏览器测试：安装 Chrome，运行 `npm install` 后运行 `npm run test:browser`；也可设置 `PULSE_BROWSER_CHANNEL=msedge` 使用 Edge。只有开发验证使用 Playwright，APK 不依赖它。

音频自动验证：`npm run test:audio`。它检查实际离线渲染的声音样本、峰值与开关行为，不等同于手机扬声器的主观听感或真机震动测试。

安卓重新打包详见 [README-android.md](README-android.md)。新环境先运行 `python tools/bootstrap-android.py`，再运行 `npm run build:android`。

安装包使用项目本地开发签名，可直接安装体验。源码压缩包不包含大型 SDK、JDK、模拟器或签名私钥；当前工作目录中的 `android/signing/local-development.jks` 可保留用于后续覆盖更新。新的签名密钥无法直接覆盖旧签名安装包。
